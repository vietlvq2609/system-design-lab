# System Design Lab

System Design Lab is a workspace for designing, documenting, and testing scalable distributed systems using a Docs-as-Code methodology.

## Repository Structure & Pointers

- `projects/`: Individual system design studies.
- `template/`: Blueprint directory and structural guide for system design projects -> [template/README.md](./template/README.md).
- `GLOSSARY.md`: Shared system design terminology and mental models -> [GLOSSARY.md](./GLOSSARY.md).
